# Polski bez paniki — poprawiony zestaw

To uproszczona, samowystarczalna wersja do GitHub Pages. Nie wymaga folderu `assets`.

1. Otwórz repozytorium `polski-bez-paniki/test`.
2. Prześlij WSZYSTKIE sześć plików HTML do katalogu głównego (`/`).
3. Zatwierdź `Commit changes`.
4. Odśwież stronę przez `Cmd + Shift + R` lub otwórz `https://polski-bez-paniki.github.io/test/index.html?v=2`.

Pliki: index.html, zajecia.html, o-mnie.html, materialy.html, kontakt.html, fiszki.html.

Wersja ma CSS i JavaScript osadzone w HTML. Usuwa błąd z widocznym tekstem `{tx(...)}` oraz problem braku arkusza stylów przy pominięciu folderu `assets`.

Formularz kontaktowy jest demonstracyjny i nie wysyła wiadomości. Postępy fiszek zapisują się w przeglądarce.
